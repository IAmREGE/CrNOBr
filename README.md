## CrNOBr
A Minecraft mod / plugin lets you escape away from creepers' destruction

### Have you ever…
* been annoyed by [creepers](https://minecraft.wiki/w/Creeper) destroying your terrains, but you don't want to turn off [Mob Griefing](https://minecraft.wiki/w/Game_rule#mob_griefing)?
* expected to fuse creepers at proper positions, but they accidentally explode in wrong places?
* just wanted to let creepers modify terrains with your consent?

This mod / plugin is right here for you!

### Supported Minecraft Versions & Loaders
Different supported Minecraft versions & loaders are indicated by the mod version suffixes:
* Fabric & NeoForge
  * `+mc1.7.x`: for [Minecraft 1.7.x](https://minecraft.wiki/w/The_Update_that_Changed_the_World) on Legacy Fabric
  * `+mc1.12.x`: for [Minecraft 1.8](https://minecraft.wiki/w/Java_Edition_1.8) to [Minecraft 1.12.2](https://minecraft.wiki/w/Java_Edition_1.12.2) on Legacy Fabric
  * `+mc1.13.x`: for [Minecraft 1.13.2](https://minecraft.wiki/w/Java_Edition_1.13.2) on Legacy Fabric
  * `+mc1.x`: for [Minecraft 1.14](https://minecraft.wiki/w/Java_Edition_1.14) to [Minecraft 1.21.11](https://minecraft.wiki/w/Java_Edition_1.21.11) on Fabric
  * `+mc26.x`: for versions since [Minecraft 26.1](https://minecraft.wiki/w/Java_Edition_26.1) on Fabric, and versions since [Minecraft 1.20.2](https://minecraft.wiki/w/Java_Edition_1.20.2) on NeoForge
* Minecraft Forge
  * `+forge1.7.x`: for [Minecraft 1.7.x](https://minecraft.wiki/w/The_Update_that_Changed_the_World) on Minecraft Forge
    * Requires [UniMixins](https://modrinth.com/mod/unimixins)
  * `+forge1.12.x`: for [Minecraft 1.8](https://minecraft.wiki/w/Java_Edition_1.8) to [Minecraft 1.12.2](https://minecraft.wiki/w/Java_Edition_1.12.2) on Minecraft Forge
    * Requires [MixinBooter](https://modrinth.com/mod/mixinbooter) 
  * `+forge1.16.x`: for [Minecraft 1.13](https://minecraft.wiki/w/Java_Edition_1.13) to [Minecraft 1.16.5](https://minecraft.wiki/w/Java_Edition_1.16.5) on Minecraft Forge
    * Requires MixinTweaker implementation on Minecraft versions before 1.15.2
  * `+forge1.20.4`: for [Minecraft 1.17](https://minecraft.wiki/w/Java_Edition_1.17) to [Minecraft 1.20.4](https://minecraft.wiki/w/Java_Edition_1.20.4) on Minecraft Forge
  * `+forge26.x`: for versions since [Minecraft 1.20.6](https://minecraft.wiki/w/Java_Edition_1.20.6) on Minecraft Forge
* `+spigot`: for versions since [Minecraft 1.8](https://minecraft.wiki/w/Java_Edition_1.8) on Spigot and Paper (compatible with Purpur in theory)

Minecraft whose versions older than 1.7 are not supported since creepers there cannot be ignited by players.

### How It Works
This mod / plugin makes creeper explosions break no blocks if the creepers have not been ignited by players (e.g. by right-clicking creepers with [flint and steel](https://minecraft.wiki/w/Flint_and_Steel) held). That's it.  
It works on logical server side—no clientside installation required! It also works in singleplayer.
